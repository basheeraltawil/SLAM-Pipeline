Input: RGB-D Frames

The system takes synchronized RGB-D frames as input. Each frame consists of:

RGB Image: Color information (640×480 pixels) providing texture and appearance data.

Depth Image: Per-pixel depth measurements aligned with RGB data, enabling 3D reconstruction.

Timestamp: For temporal synchronization between frames and with other sensors.

Why this matters

RGB-D sensors provide both visual appearance and geometric information, enabling more robust 3D perception than RGB-only systems. Depth data is essential for accurate scale estimation in monocular SLAM.

Semantic Segmentation

Identifies and segments dynamic objects using deep learning models:

YOLOv8 Detection: Detects potential dynamic objects (people, vehicles) and outputs bounding boxes with confidence scores. Filters low-confidence detections (<0.7).

SAM2 Segmentation: Uses bounding boxes as prompts to generate pixel-accurate masks. SAM2's transformer architecture enables zero-shot generalization to unseen objects.

Propagation Strategy: Efficiently handles new objects entering the scene by triggering new segmentation when detection confidence exceeds threshold.

Why this matters

Semantic segmentation provides prior knowledge about dynamic elements, allowing the system to proactively remove features that would corrupt the map and trajectory estimation. The YOLOv8 + SAM2 combination achieves high precision with real-time performance.

Dynamic Feature Removal

Two-stage approach to eliminate dynamic features:

Semantic Mask Filtering: Discards ORB features inside SAM2 masks using: features = [f for f in features if not mask[f.position]]

Epipolar Geometric Constraints: Computes fundamental matrix using RANSAC and calculates point-to-epipolar-line distance:
d = |x'ᵀ F x| / √(a² + b²)
Features with d > 2.0px are classified as dynamic.

Validation: Cross-validates results from both methods for robust filtering.

Why this matters

While semantic filtering handles known dynamic objects, geometric constraints catch unexpected motion (e.g., moved furniture). This dual approach ensures robustness against both anticipated and unanticipated dynamic elements.

Feature Extraction

Extracts robust features from static regions:

ORB Point Features: Detects multiscale corners in static regions. Computes 256-bit BRIEF descriptors with orientation. Parameters: 1000 features/frame, pyramid levels=8.

EDLines: Detects line segments using edge grouping. Processes image pyramid (scale=1.2) for multiscale robustness. Outputs line endpoints (x₁,y₁,x₂,y₂).

Descriptor Computation: ORB features use oriented BRIEF descriptors. Lines use Line Band Descriptors (LBD) for robust matching.

Why this matters

Line features provide structural constraints in texture-less areas where point features fail. The combination of points and lines ensures feature availability even when dynamic objects dominate the scene.

Tracking

Estimates camera pose through feature matching:

Feature Matching: Points are matched using FLANN with ratio test (0.8). Lines are matched using LBD descriptors with geometric validation. Rejects matches with Hamming distance > 50.

Pose Estimation: Solves Perspective-n-Point (PnP) problem using RANSAC:
min Σ ‖ π(K(RXᵢ + t)) - xᵢ ‖²
Uses both points and lines as constraints.

Motion Prediction: Employs constant velocity model to initialize pose estimation and reduce search space.

Why this matters

The combination of point and line features provides more constraints for pose estimation, especially when dynamic filtering reduces the number of available point features. This dual approach maintains tracking robustness in challenging conditions.

Mapping

Builds and optimizes the environment map:

Adaptive Bundle Adjustment: Joint optimization of points and lines with adaptive weighting:
α = 2^(-|Pₖ|/λ) (λ=50)
Cost function:
E = Σ e_point + αΣ(e_line²ᴰ + e_line³ᴰ)

Map Optimization: Performs local BA in keyframes. Represents lines with 3D endpoints and Plücker coordinates.

Dense Reconstruction: Projects static pixels into 3D using depth data. Uses Truncated Signed Distance Function (TSDF) for surface reconstruction. Removes dynamic regions using semantic masks.

Why this matters

The adaptive weighting balances the contribution of point and line features based on availability. When points are abundant, lines have less influence, reducing potential errors from line mismatches. In sparse point environments, line features compensate to maintain map quality.

Output

Final outputs of the SLAM system:

Camera Trajectory: 6-DoF camera poses over time in the format:
[timestamp, x, y, z, qx, qy, qz, qw]
Saved as trajectory.txt for evaluation.

Dense 3D Map: Point cloud (PLY/PCD format) with dynamic objects removed:
point_cloud = point_cloud[static_mask]

Performance Metrics: Calculates Absolute Trajectory Error (ATE) and Relative Pose Error (RPE) for evaluation.

Why this matters

The clean trajectory and dynamic-free map enable reliable navigation and environment interaction for autonomous systems. Performance metrics demonstrate the system's 98.33% improvement over ORB-SLAM2 in dynamic environments.
